Survey notes: what production work would change?
Already exists

assignBlockIds() gives each top-level Markdown block a stable data-block-id. New block comments already persist that id.

Main change

For comments with block_id, decorate the matching block element instead of wrapping its full text in <mark>. Keep text marks for legacy comments without a block id.

Important edge

Multiple comments can share a block. Active, resolved, author, and tag state must be represented without changing line wrapping or losing click-to-focus behavior.
