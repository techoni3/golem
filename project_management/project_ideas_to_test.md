## FactScroll App
Project: A webapp similar to Instagram Reels but featuring interesting, AI-generated facts/factoids on scrollable screens, paired with contextually fitting background images instead of short videos.
Patches:
    - proactively pre-generate upcoming screens to eliminate loading wait times during scrolling
    - implement standard app features (user accounts, likes, sharing, etc.)
    - incorporate an adaptive learning system that personalizes the feed based on user preferences and scrolling behavior (tracked via in-profile data and interaction metrics)
